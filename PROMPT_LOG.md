# AI Collaboration & Prompt Log (`PROMPT_LOG.md`)

This document details the interaction with the AI assistant during the development of the visualization module (Section 3), highlighting the iterative prompt refinement and bug-fixing process.

---

## 1. Initial Prompt to the AI

> **Prompt:**  
> *"Write a Python script named `visualize.py` that reads the aggregated telemetry results from `output/summary.json` and creates a bar chart comparing the average temperature per device using `matplotlib`. Save the generated plot as `output/avg_temp_chart.png`."*

---

## 2. Bug / Formatting Mistakes in First Attempt

Upon running the initial script generated by the AI, several formatting and usability issues were identified during code review:
1. **Label & Boundary Clipping:** The plot did not invoke `plt.tight_layout()`, causing device labels on the x-axis and the title margins to get clipped on standard export resolutions.
2. **Missing In-Bar Value Annotations:** The bars only provided visual height without explicit data values. To know the exact temperature, a user had to manually trace the grid across to the y-axis.
3. **No Top Margin Headroom:** The y-axis upper limit was automatically set to `max(temperatures)`, which caused the tallest bar to touch the top border of the plot canvas.
4. **No Graceful Error Handling:** If `output/summary.json` was missing or contained an empty list, the script crashed with an unhandled exception rather than logging an informative warning.

---

## 3. Follow-Up Prompt to Fix the Issues

> **Follow-Up Prompt:**  
> *"The initial chart works, but needs formatting improvements and robustness fixes:*  
> *1. Add numeric text labels directly above each bar displaying the exact average temperature formatted to two decimal places (e.g., `45.23°C`).*  
> *2. Expand the y-axis limit dynamically (`ylim(0, max_temp + 15)`) to give breathing room for the value labels.*  
> *3. Add `plt.tight_layout()` and set `dpi=300` when saving to prevent label clipping.*  
> *4. Add subtle horizontal dashed gridlines behind the bars (`set_axisbelow(True)`) for easier visual comparison.*  
> *5. Wrap file loading with clean error handling in case the JSON file is missing or empty.*"

---

## 4. Outcome & Review

The revised script (`src/visualize.py`) resolved all issues:
- Clear, readable typography and modern styling.
- Exact temperature readouts above each bar.
- Robust exception handling when reading input files.
- High-resolution (300 DPI) export ready for inclusion in reports.
